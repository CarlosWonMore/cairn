# agent-onboarding Specification

## Purpose
让个人用户能够从可公开识别的 Agent 记忆与规则来源安全建立初版记忆库，并在不破坏原有使用方式的前提下逐步启用本产品。

## Requirements

### Requirement: 元数据发现与显式选择
系统 SHALL 仅对用户明确允许的位置进行来源发现；发现阶段 MUST 只返回类型、路径、大小等元数据，不得读取正文或跟随不受信链接。

#### Scenario: 首次发现本机来源
- **WHEN** 用户执行发现但尚未选择导入
- **THEN** 系统列出可识别来源及能力边界，正文读取计数为零，且不改变任何来源文件

#### Scenario: 遇到私有数据库或符号链接
- **WHEN** 候选来源需要未公开接口或指向允许范围之外
- **THEN** 系统标为不支持并跳过，不尝试逆向或越界读取

### Requirement: 三类操作独立授权
系统 SHALL 将记忆导入、MCP 配置和原生记忆修改作为三个独立授权动作，MUST NOT 用一次初始化默认捆绑执行。

#### Scenario: 用户只授权导入
- **WHEN** 用户勾选来源并确认导入但未批准配置修改
- **THEN** 系统只创建导入档案，不写 MCP 配置或原生记忆文件

### Requirement: 不可变快照与默认本地档案
系统 SHALL 在授权后创建带来源哈希的不可变快照；导入内容 SHALL 默认为 `imported_unverified` 与 `local_only`，源文件 MUST 保持不变。

#### Scenario: 重复导入同一来源
- **WHEN** 用户重复导入哈希未变化的同一来源
- **THEN** 系统复用已有档案且不产生重复记忆或重复上传任务

#### Scenario: 模型不可用
- **WHEN** 导入完成后模型不可用或整理任务中断
- **THEN** 用户仍可在本地检索、导出原始档案，且其未验证状态保持清晰

### Requirement: 对话式分批初始化
系统 SHALL 支持当前 Agent 对已授权批次提出新增、合并、保留双方或跳过建议，并 SHALL 在真实批准后分批应用和保存可续跑进度。

#### Scenario: 用户在对话中初始化记忆
- **WHEN** 用户明确要求整理一个已授权批次
- **THEN** Agent 只能读取该批次并生成治理计划，系统展示差异，经有效审批后才晋升为正式记忆

#### Scenario: 会话中断后继续
- **WHEN** Agent 会话在批次完成前终止
- **THEN** 用户可在新会话继续未完成批次，不重复已应用操作，也不扩大原授权范围

### Requirement: 原生记忆渐进接管
系统 SHALL 默认保留 Agent 原生记忆，提供 `observe`、`router` 和准备式 `mcp-primary` 模式；实际关闭原生能力 MUST 需要独立确认且只能使用公开支持的方式。

#### Scenario: 默认路由模式
- **WHEN** 用户选择 `router`
- **THEN** 系统仅添加简短受管入口，将跨设备共享记忆指向本产品，同时保留 Agent 私有原生草稿

#### Scenario: 原生能力无公开关闭接口
- **WHEN** 用户选择 `mcp-primary` 但宿主没有公开关闭方式
- **THEN** 系统只提供备份和手动步骤，不宣称已接管或关闭原生记忆

### Requirement: 受管入口可精确移除
系统 SHALL 只修改带唯一标记的原生说明区块，确保重复写入幂等且卸载可精确移除；自然语言入口 MUST NOT 被当作权限或隔离机制。

#### Scenario: 卸载路由入口
- **WHEN** 用户移除本产品路由入口且原生文件无其他后续变化
- **THEN** 系统恢复原文件字节，不影响其他规则、记忆或 MCP 条目

### Requirement: 用户级全局入口与项目级入口的叠加

系统 SHALL 支持把 router 受管入口写入宿主的用户级全局规则文件，使该宿主的所有工作区都被覆盖，而不必逐项目写入。

系统 MUST 说明用户级与项目级入口是**叠加**（用户级先、项目级后，后者更具体因此优先），MUST NOT 表述为二者互相替代。

#### Scenario: 写入用户级入口

- **WHEN** 用户对支持用户级全局规则文件的宿主选择 router 模式
- **THEN** 系统写入该全局文件的受管区块，且不为每个项目各写一份

#### Scenario: 同时存在两级入口

- **WHEN** 用户级与项目级规则文件中都存在本产品受管区块
- **THEN** 两处区块各自保持完整且可独立移除，移除其中一处不影响另一处

#### Scenario: 宿主无用户级全局规则文件

- **WHEN** 宿主只提供项目级规则文件
- **THEN** 系统维持项目级落点并说明该宿主没有用户级全局文件，不写入推测路径
