## ADDED Requirements

### Requirement: 标签语言可切换且不损失原始值

系统 SHALL 提供「中文标签」与「原文」两态可切换的标签呈现模式，切换入口 MUST 位于工具栏且与主题、摘要/全文切换同级；MUST 默认使用中文标签。两态 MUST 只改变人读文案，MUST NOT 改变任何数据面的值、顺序或数量。

中文模式下，系统 MUST 为下列领域枚举提供中文标签：记忆 `kind`（8 个）、记忆 `status`（6 个）、`authority`（4 个）、作用域 `preset` 与 `syncPolicy`、导入条目与批次的 `scanState` 与 `redactionState`。映射表 MUST 单点定义，MUST NOT 在各处模板字符串内各写一份。

中文模式下，每个被翻译的标签 MUST 通过 `title` 属性保留其原始枚举值，使用户无需切回原文模式即可确认库中真实取值。原文模式下所有标签 MUST 与引入本能力之前逐字节一致。

#### Scenario: 默认显示中文标签
- **WHEN** 用户首次打开控制台并进入记忆视图
- **THEN** 记忆卡片的作用域、种类、状态与权威显示为中文标签，界面文案整体为中文

#### Scenario: 切回原文标签
- **WHEN** 用户点击标签语言切换按钮切到「原文」
- **THEN** 所有标签立即变为原始枚举值（`decision` / `active` / `user_explicit` 等），且不触发任何数据重新请求

#### Scenario: 中文模式下仍能看到原始值
- **WHEN** 处于中文模式，用户把指针悬停在任一已翻译标签上
- **THEN** 提示文本给出该标签对应的原始枚举值

#### Scenario: 未知枚举不崩不留空
- **GIVEN** 库中存在映射表未覆盖的枚举值（例如将来新增的 `kind`）
- **WHEN** 渲染该标签
- **THEN** 系统原样显示该值而不是空白、`undefined` 或抛错

### Requirement: 语言选择可恢复

标签语言 SHALL 与主题、展示模式采用同一套状态持久化机制；刷新页面或在新标签页打开同一地址后 MUST 保持原选择。该状态 MUST NOT 与服务端查询参数混淆，MUST NOT 触发额外请求。

#### Scenario: 刷新后保持选择
- **WHEN** 用户切到「原文」标签并刷新页面
- **THEN** 页面仍以原文标签渲染，无需再次切换

#### Scenario: 静态导出页同样可切换
- **WHEN** 用户打开静态导出的预览页并切换标签语言
- **THEN** 标签随之变化，且不发起任何网络请求
