# Proposal

## Why

个人在多台设备、多个 Agent 之间切换时，偏好、项目事实、设备约束和阶段性进展分散在各宿主的原生记忆中，缺少统一的作用域、来源、迁移、冲突和删除治理。现有 Agent 的记忆能力与公开接口并不一致，不能靠逆向私有数据库实现所谓“全兼容”。

M0 已用合成数据证明本地 SQLite、中文检索、MCP stdio、临时 HOME 配置合并和初始化审批合同具有可实现性；现在需要把相互独立的探针收敛成一个可审查、可回滚、无模型也可用的本地 MVP，而不是继续堆叠孤立演示。

## What Changes

- 新建独立的 TypeScript + Node.js 22+ 核心与 npm 包结构；长期运行固定版本，提供 npx 试用入口，不以 uvx 为主分发。
- 建立每设备本地 SQLite 权威库、版本化迁移、备份恢复、来源与修订记录；数据库是唯一运行真相源，Markdown 只做受管投影。
- 提供个人公共、设备本地、项目、Agent 私有等预设作用域及受约束自定义空间；同一策略约束写入、检索、投影、导出与后续同步。
- 实现显式记忆的新增、查询、详情、更正、遗忘和导出；中文检索采用评测选择的 FTS5 与短查询回退，不依赖 LLM。
- 实现候选、导入未验证、用户明确和用户确认等权威级别；合并计划绑定 `plan_hash` 与一次性审批，伪造确认、过期计划和篡改计划必须失败。
- 提供 CLI 与 MCP stdio 接口；stdout 只输出 JSON-RPC，日志只写 stderr 或文件。后台 outbox 只建立本地可靠任务边界，不在本变更连接真实云端。
- 提供首次初始化的安全闭环：元数据发现、用户勾选、不可变导入快照、去重合并计划、分批确认、可恢复续跑；默认 `observe`/`router`，不静默接管原生记忆。
- 提供 `agent plan/apply/doctor/uninstall` 配置合同与临时 HOME 测试；真实配置修改必须是独立授权步骤，并可精确卸载本产品条目。
- 建立合成数据、故障注入、恶意记忆、秘密阻断、幂等、并发、备份恢复和 stdio 隔离测试，形成机器可读验收结果。

## Capabilities

### New Capabilities

- `memory-store`: 本地权威记录、作用域、来源、修订、生命周期、迁移、备份和导出。
- `scoped-retrieval`: 受作用域约束的中文混合检索、来源追溯与投影前过滤。
- `memory-governance`: 候选抽取协议、合并计划、真实审批、冲突保留、秘密阻断和幂等应用。
- `agent-onboarding`: Agent 来源发现、授权快照导入、分批初始化、受管原生入口与配置回滚。
- `agent-interfaces`: CLI、MCP stdio、后台任务隔离、健康检查和可精确卸载的宿主接入。

### Modified Capabilities

无。本仓库尚无已归档能力规格。

## Impact

- 影响范围仅限新项目的核心包、CLI/MCP 入口、迁移、测试、 fixtures 与文档；不修改其他仓库。
- `artifacts/m0/` 中的代码是原型证据，须按本变更规格重构与复核，不直接等同于生产实现。
- 预计使用 Node.js 22+、SQLite/FTS5 和官方 MCP SDK；SQLite 驱动的最终选择由设计阶段依据 M0 证据与打包验证决定。
- 首变更只定义本地 outbox 与远端能力接口，不创建 ECS/OBS 资源、不写入真实云端、不安装系统级服务。
- 默认仅使用合成 HOME、合成记忆和本地 fake backend；真实 Agent 接入必须另获用户明确授权。

## 非目标与当前决策

- 不考虑本地模型，不下载模型或推理运行时，也不把本地模型评测列为阻塞。
- 不做团队共享、组织权限、图数据库、完整聊天记录仓库或规格驱动开发流程。
- 不逆向读取 Agent 私有数据库，不承诺实时双向同步原生记忆，不默认关闭宿主原生记忆。
- 不让模型直接写长期活动记忆，不自动静默扫描、迁移、清空或扩大记忆作用域。
- 不在本变更实施真实 ECS/OBS 同步、托管 relay、桌面 Pro 功能或云端自动抽取。

## 风险与回滚

- 数据风险：迁移前必须备份；错误候选不得直接覆盖用户明确记忆，冲突双方保留，遗忘采用可审计 tombstone。
- 配置风险：`plan` 零写入，`apply` 仅接受绑定当前计划的真实审批，修改前备份，`uninstall` 只移除本产品配置。
- 会话风险：网络、模型、worker 与维护任务均退出 Agent 关键路径；任何后台失败只能留下可重试状态。
- 隐私风险：发现阶段不读正文，导入默认 `imported_unverified + local_only`，疑似秘密在进入 Agent 批次前阻断。
- 回滚：可卸载 MCP/受管区块、恢复配置备份、从数据库备份恢复并重新生成投影；本变更没有云端写入，因此不存在云端回滚前提。

详细调研、原型证据和未完成外部验证见 `docs/M0-session-handoff.md` 与 `artifacts/m0/`；这些证据不被表述为真实云端、全平台或全 Agent 认证。
