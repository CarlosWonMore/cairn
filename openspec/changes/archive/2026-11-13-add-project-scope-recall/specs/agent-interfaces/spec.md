## ADDED Requirements

### Requirement: 自动召回可携带显式配置的项目身份

宿主插件 SHALL 支持通过显式配置声明项目身份（路径或 git URL 形式的别名）；配置后，插件的自动召回检索 SHALL 携带经解析的项目标识，使项目作用域记忆可进入召回。

项目身份 MUST 只来自显式配置或显式参数，MUST NOT 从工作目录、打开文件等环境线索自动推断。插件 SHALL 在加载配置时经既有解析入口完成解析与登记（find-or-create），并缓存解析结果。

解析失败时插件 MUST 降级为不带项目身份的召回（行为与未配置一致），MUST 在面板状态中如实呈现降级原因，MUST NOT 静默假装已携带项目身份。未配置项目身份时，插件行为 MUST 与现状逐字节一致。

#### Scenario: 配置项目后召回项目记忆
- **GIVEN** 插件配置了项目别名 A，且 A 已解析为项目 P，P 下存在命中当前查询的 project-global 记忆
- **WHEN** 自动召回执行检索
- **THEN** 该记忆可进入注入候选，与 personal-global 记忆同等参与排序与预算

#### Scenario: 未配置时行为不变
- **WHEN** 插件未配置项目身份
- **THEN** 检索不携带项目参数，召回结果与不携带时的语义一致

#### Scenario: 解析失败时降级并如实提示
- **GIVEN** 配置的别名无法解析为已登记项目且解析入口调用失败
- **WHEN** 插件执行自动召回
- **THEN** 检索降级为不带项目身份（personal-global 等照常召回），面板状态显示降级原因，不静默继续
