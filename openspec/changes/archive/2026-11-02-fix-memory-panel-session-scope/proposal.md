# Proposal: 记忆面板按会话隔离（并支持点选高亮）

## Why

用户实测发现：**每个会话的记忆 tab 里都叠着所有会话的活动记录**。查代码后确认这不是显示层的小毛病，而是三处状态都是**插件级单例**：

| 状态 | 原实现 | 后果 |
|---|---|---|
| 活动记录 `activity[]` | apply() 时建一个数组 | 所有会话共用同一环，面板互相串台 |
| 「最近一次注入」`lastUsage` | injector 里的一个变量 | 面板显示的永远是「最后跑过的那一步」，与当前会话无关 |
| 去重集合 `dedupe` | injector 里的一个 Set | **A 会话注入过的记忆，B 会话再也不会被注入** |

最后一条是功能缺陷，不只是显示问题：`agent-interfaces` 已经规定「同一会话内已注入过的记忆 MUST NOT 重复注入」，现实现把它做成了「全局只注入一次」，把跨会话的正常召回也挡掉了。

另外用户提出：「本轮注入」这个口径不好理解——想知道的是**本会话一共注入过哪些记忆（去重）**；并且希望右侧记录可以点选，联动高亮左侧对应的记忆。

## What Changes

1. **按会话切片**：所有状态（injector / 去重集合 / 活动环 / 本会话累计注入）改为 `Map<sessionId, SessionState>`。会话键取 `agent.id`（`Agent.id` 就是 `SessionId`）。
2. **端点带会话**：面板请求 `/usage?session=<id>`；不带参数（curl 自检）时返回最近活跃会话。
3. **左下改口径**：从「本轮注入」改为「本会话注入的记忆（去重）」——这正是用户要的那份列表。
4. **点选联动**：活动记录里的「自动召回」条目携带 `items`（id / 类型 / 摘要）；点选后左侧同 id 的条目高亮（背景 + 左侧色条），再点一次取消。
5. **落盘不写 items**：摘要也是正文的前缀，长期留存面不该有它。代价是重启后「本会话累计注入」从空开始。

### 不改什么

- 不改检索、过滤、预算、摘要生成。
- 不改 `cairn ui` 控制台。
- 不引入新的存储：会话状态全在内存，随宿主重启消失（与既有的内存环一致）。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-interfaces`：面板 MUST 只呈现当前会话的数据；「本会话注入过的记忆」MUST 去重且跨轮累计；去重 MUST 按会话隔离（不同会话各自独立）；活动记录 MUST 可点选并高亮其对应的注入条目；落盘日志 MUST NOT 包含记忆内容（含摘要）。

## Impact

- 修改：`plugin/dsh/src/index.ts`（会话状态机 + 端点 + 回放）、`plugin/dsh/src/client.js`（props.sessionId、累计列表、点选高亮）。
- 测试：`plugin/dsh/tests/injector.test.ts`（会话隔离、端点切片、最近活跃回落）、`plugin/dsh/tests/panel-render.test.ts`（累计列表、点选高亮）。
- 风险：
  - **会话 id 取错**（`Agent.id` 与 slot 传的 sessionId 不一致）→ 面板会显示空列表而不是别人的数据。这是刻意的失败方向：宁可空，也不串台。
  - **重启后累计列表为空** → 已知取舍，写进 README。
  - 旧落盘行没有会话字段 → 落到 `default` 桶，不出现在任何真实会话面板里。
