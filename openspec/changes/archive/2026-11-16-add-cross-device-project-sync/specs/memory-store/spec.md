## ADDED Requirements

### Requirement: 不再持有的副本携带终态作用域

当一台设备收到某条记忆的迁出通知时，本地留存副本 SHALL 记录该记忆的**终态作用域**（发出端迁往的作用域：个人全局 / 项目全局（含项目身份）/ 设备限定（含归属设备）/ 其他），并据此在列表与详情中如实展示。该记录 MUST NOT 复制内容、MUST NOT 产生墓碑、MUST NOT 改变遗忘时间线。

终态作用域 MUST NOT 参与读取授权判定——读取授权仍以本地作用域为唯一依据；被标记为不再持有的副本 MUST NOT 作为活动内容被检索返回。

#### Scenario: 项目作用域终态如实展示

- **GIVEN** 一条本地留存副本对应的记忆已被发出端迁入项目 P
- **WHEN** 本机收到该记忆的迁出通知
- **THEN** 该副本的展示作用域为项目 P，且状态为不再持有

#### Scenario: 设备限定终态如实展示

- **GIVEN** 一条本地留存副本对应的记忆已被发出端迁入设备限定作用域，发出端设备为 A
- **WHEN** 本机收到该记忆的迁出通知
- **THEN** 该副本的展示作用域为「设备限定」并携带归属设备 A，且本机不因此获得该记忆的正常持有

#### Scenario: 未知终态的降级

- **GIVEN** 一条迁出通知来自不支持终态描述符的旧版本设备
- **WHEN** 本机应用该通知
- **THEN** 该副本仍被标记为不再持有，终态作用域显示为未知，不产生错误或中断

#### Scenario: 终态不改变授权

- **GIVEN** 一条被标记为不再持有的副本，其终态作用域为项目 P
- **WHEN** 当前 Agent 请求读取该项目作用域的记忆
- **THEN** 授权判定结果与终态作用域无关，仍按本地作用域策略执行
