## ADDED Requirements

### Requirement: 记忆携带归属设备

每条记忆 SHALL 记录其归属设备：本机创建的记忆记录本机设备标识；经同步到达的记忆记录**来源设备**的设备标识（同步事件携带）。库中既有记忆的归属设备 SHALL 以空值表示「未知」并如实展示。

归属设备 SHALL 出现在列表与详情载荷中，供过滤与展示使用；它 MUST NOT 参与读取授权判定——读取授权仍以作用域为唯一依据。归属设备一经写入 MUST NOT 被后续修订改写。

#### Scenario: 本机创建记录本机

- **WHEN** 在本机创建一条记忆
- **THEN** 其归属设备为本机设备标识

#### Scenario: 跨设备到达记录来源

- **GIVEN** 保管模式开启（或个人全局同步）
- **WHEN** 本机应用来自设备 A 的事件并落地一条记忆
- **THEN** 该记忆的归属设备记录为设备 A

#### Scenario: 既有记忆未知如实展示

- **WHEN** 列出一条本变更之前已存在、未回填来源的记忆
- **THEN** 其归属设备为「未知」，展示不隐藏该状态

#### Scenario: 归属设备不参与授权

- **GIVEN** 一条归属设备为 A 的记忆，其作用域读取策略不允许当前 Agent 读取
- **WHEN** 当前 Agent 请求该记忆
- **THEN** 授权判定结果与归属设备无关，仍按作用域拒绝
