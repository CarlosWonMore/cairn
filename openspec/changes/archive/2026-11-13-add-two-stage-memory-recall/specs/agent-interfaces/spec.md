## ADDED Requirements

### Requirement: 注入内容携带可下钻的记忆标识

宿主插件的注入行 SHALL 携带所注入记忆的标识（可与详情工具对接的短标识形式），使模型能够按标识调用 `memory_get` 获取全文。

注入行的标识 MUST NOT 替代既有摘要：标识之外的摘要内容、注入预算与会话去重语义 MUST 保持不变。工具描述 SHALL 内嵌两段式检索纪律（先看列表预览，确需全文再按标识取全文），MUST NOT 引导模型未经预览直接批量取全文。

#### Scenario: 模型按注入行标识取全文
- **GIVEN** 某轮注入了一条记忆，注入行携带其短标识
- **WHEN** 模型需要该记忆全文并以该标识调用 `memory_get`
- **THEN** 详情工具按标识解析出唯一记忆并返回全文

#### Scenario: 标识不改变注入预算与去重
- **WHEN** 注入行加入标识后同轮命中多条记忆
- **THEN** 注入总预算与超预算裁剪规则不变，会话去重仍按完整记忆 id 判定

#### Scenario: 工具描述声明两段式纪律
- **WHEN** 调用方查看检索与详情工具的描述
- **THEN** 描述说明「列表返回预览、全文经详情获取」的用法，而非宣称列表返回全文
