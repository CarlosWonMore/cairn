## ADDED Requirements

### Requirement: 检索返回命中时留下使用痕迹

系统 SHALL 在显式检索返回结果时，为实际返回的记忆更新使用信号；更新 MUST 只覆盖真正返回给调用方的那部分记忆，MUST NOT 波及被过滤掉的候选。

#### Scenario: 检索命中写入使用痕迹
- **WHEN** 显式检索返回三条命中
- **THEN** 系统只更新这三条记忆的最近使用时间与请求次数，未返回的候选保持原状

#### Scenario: 检索被截断到上限
- **WHEN** 检索按上限截断后返回前若干条
- **THEN** 只有被返回的那些条记录使用痕迹

#### Scenario: 使用痕迹写入失败不改变检索结果
- **WHEN** 更新使用痕迹的写入失败
- **THEN** 系统仍返回既定检索结果，不因写失败而报错或返回空集

#### Scenario: 检索只读语义的例外边界
- **WHEN** 调用方以只读身份执行检索
- **THEN** 系统 MUST NOT 写入使用痕迹，检索保持只读

#### Scenario: 宿主自动召回不增加请求次数
- **WHEN** 宿主插件的自动召回经检索接口取回命中并注入上下文
- **THEN** 系统可更新这些命中的最近使用时间，但 MUST NOT 增加其被主动请求次数
