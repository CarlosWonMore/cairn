## ADDED Requirements

### Requirement: 内容重复不产生重复记忆

系统 SHALL 在显式写入、计划生成与应用三个环节消除同一作用域内的正文重复，且三个环节 MUST 共用同一判定。显式写入时 MUST 检查该作用域是否已存在规范化正文相同的 active 记忆；生成计划时 MUST 把规范化正文相同的多个条目合并为一个操作，其余条目 MUST 标记为重复并指向被合并的条目；执行 `add` 前 MUST 检查同一条件，存在时 MUST 追加证据与来源而不新建记忆。

#### Scenario: 同一内容被会话反复记下
- **WHEN** Agent 在两个不同会话里写入规范化正文完全相同、作用域相同的记忆
- **THEN** 该作用域只有一条 active 记忆，第二次写入返回命中的既有记忆标识与去重标记，不新建记录

#### Scenario: 写入与晋升判定一致
- **WHEN** 同一段正文先经显式写入落库，随后又作为快照条目申请晋升到同一作用域
- **THEN** 晋升不产生第二条记忆，判定结果与写入时一致，MUST NOT 出现两个环节结论相反的情况

#### Scenario: 同一内容来自多个快照
- **WHEN** 三个批次各自含有一段完全相同的正文，且都申请晋升到同一作用域
- **THEN** 最终该作用域只有一条 active 记忆，其来源证据指向三个批次，审计中记录两次合并

#### Scenario: 重复执行同一计划
- **WHEN** 同一计划因中断重试被再次应用
- **THEN** 不产生第二条记忆，只追加证据，返回结果标明为幂等命中

#### Scenario: 用户要求两条并存
- **WHEN** 操作为 `keep_both` 且显式给出目标记忆，或写入时显式声明两条并存
- **THEN** 系统新建一条记忆并与目标建立矛盾关系，MUST NOT 按重复合并

#### Scenario: 相同内容处于不同作用域
- **WHEN** 同一段正文分别晋升或写入 `device-local` 与 `project-global`
- **THEN** 系统在各自作用域各保留一条记忆，MUST NOT 跨作用域合并

#### Scenario: 重复条目在待决策中可见
- **WHEN** 某条目因正文重复被标记而不是被晋升
- **THEN** 待决策队列如实显示它被判定为重复及所指的目标条目，MUST NOT 静默丢弃
